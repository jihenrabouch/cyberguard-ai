- conserver un lien vers le document source lorsque cela est raisonnablement possible ;
- indiquer les modifications apportées ;
- partager les adaptations sous CC BY-SA 4.0 ou une licence compatible.

**Important :** le statut de licence du projet ne signifie pas nécessairement que chaque image, illustration ou ressource tierce intégrée dans un document est couverte. Vérifier les éléments tiers avant de les redistribuer. Le corpus proposé ici privilégie les fichiers Markdown sources. Vérifier à nouveau la licence et les fichiers au moment du téléchargement, car le dépôt peut évoluer.

## Note de collecte

Les URL ci-dessus pointent vers les fichiers du dépôt officiel. Le script `scripts/download_owasp_corpus.py` télécharge les fichiers dans `data/raw/` et échoue en cas d'erreur HTTP. Après téléchargement, vérifier que les 20 fichiers sont présents et non vides avant de les committer.
